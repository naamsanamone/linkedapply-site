## ✨ Features

- **Smart Question Answering**: Automatically answers Easy Apply form questions, experience requirements, salary expectations (LPA support), notice periods, and radio/dropdown fields.
- **ATS Match Scoring**: Evaluates your resume against real-time job descriptions to highlight required vs preferred qualifications and match compatibility.
- **On-Demand Resume Tailoring**: Generates tailored resumes with targeted keywords directly in the side panel.
- **100% Local & Zero Telemetry**: No tracking, no analytics, no external servers. All personal data stays in your browser's local storage.
- **Bring Your Own Key (BYOK)**: Supports free Google Gemini API keys, OpenAI (GPT-4o / GPT-4o-mini), DeepSeek, and custom OpenAI-compatible endpoints (Groq, Ollama).

## 🛡️ Privacy & Security Highlights

LinkedApply Pro is built with a local-first, privacy-respecting architecture:
1. **No External Database**: All profile information, preferences, and application history are stored strictly on your device via Chrome's `chrome.storage.local`.
2. **Direct AI Connection**: Your API keys connect directly and securely via HTTPS to the AI provider you configure.
3. **No LinkedIn Credential Access**: The extension only interacts with the visible DOM in your active LinkedIn tab. It never accesses or stores your passwords or login session cookies.

For complete details, please read our [Privacy Policy](https://naamsanamone.github.io/linkedapply-site/privacy.html).
